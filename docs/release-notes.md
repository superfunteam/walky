A little fresh air. A little time together.

- Big button, shared calendar, and a paper chain with interactive physics.
- Home-screen widget: tap once to log today; see the shared status.
- Offline widget taps queue safely and sync when the phone reconnects.
- Long-press Walky's app icon for the "We walked" shortcut.

Install `walky.apk`, open it, and enter `https://walky.wims.vc` plus your shared connection code. Tap **Add widget**.
